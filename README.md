 Absolute Value Finder (C++)

A simple C++ program that takes a number from the user and prints its absolute value.

## How it works
The program reads a number `x` and computes its absolute value using
`sqrt(x * x)`, since the square root of a squared number removes the sign.
EXAMPLE: If I will give the input value x=-9 then this code will return 9.
If I will give the input value x=-7 then this code will return 7.
If I will give the input value x=2 then this code will return 2.
## What I learned
^ is the XOR operator in C++, not power.
sqrt() comes from <cmath>.
